# 趣商云开源版

**趣商云（Qushangyun）** 是我开发的一套面向微信公众号运营场景的开源管理工具，主要用于将公众号日常运营中常用的客服、内容、用户和配置能力整合到统一的 Web 管理后台中。

> 项目官网：[https://qushangyun.cn](https://qushangyun.cn)

## 核心功能

- **客服工作台**：集中处理公众号用户消息，并查看用户资料、标签及互动记录。
- **素材管理**：统一管理公众号运营过程中使用的图片、文件等素材。
- **文件管理**：管理平台中的文件资源，方便在运营和客服场景中使用。
- **自动回复**：配置公众号常用的自动回复规则和回复内容。
- **公众号菜单**：可视化管理微信公众号自定义菜单。
- **带参二维码**：创建和管理公众号渠道二维码，用于不同推广场景。
- **群发管理**：管理公众号消息群发相关操作。
- **关注用户**：查看和管理公众号关注用户及用户信息。
- **互动记录**：统一查看用户与公众号之间的历史互动记录。
- **OAuth2 配置**：管理微信公众号网页授权相关配置。

## 技术栈

- **前端：** Vue 3 + Naive UI
- **后端：** NestJS + TypeScript
- **数据层：** TypeORM + MySQL

## 项目介绍

这个项目主要解决微信公众号运营过程中功能分散、操作入口较多的问题，通过一个统一的管理后台，将客服接待、内容管理、用户管理和公众号基础配置集中起来。

在开发过程中，我负责了项目的产品设计、前后端开发以及整体功能实现，并持续对项目进行迭代和开源维护。
