# 2026-08-07

## 添加 Vercel 部署脚本

- 新增 `deploy-vercel.js`（项目根目录）：封装 hexo clean → hexo generate → vercel deploy --prod 三步流程
- 通过 `npx vercel` 调用 CLI，无需全局安装；支持 `VERCEL_TOKEN` 环境变量做 CI 自动化部署
- 脚本放在根目录而非 `scripts/`，避免被 Hexo 自动加载执行
- `package.json` 的 scripts 新增 `deploy:vercel`: `node deploy-vercel.js`
- 首次使用需 `npx vercel login` 登录
- 支持通过 `VERCEL_PROJECT_NAME` 环境变量或交互式输入自定义项目名（决定域名为 `<name>.vercel.app`）
